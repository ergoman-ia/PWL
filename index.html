교육원 주변 식당 찾기

교육생용 · 구내식당 대비 평가 · 🚶 도보 기준
📍 기준점 교육원 정문

판단 배지 읽는 법 — 교육원 구내식당을 기준(0점)으로 두고, 구내식당을 먹어본 교육생의 비교 응답(−2 ~ +2)과 먹어보지 않은 교육생의 추천 응답을 함께 환산한 값입니다. ＋1.0 이상 = 나갈 만함, ＋0.3 ~ ＋1.0 = 가볼 만함, ±0.3 = 구내식당과 비슷, −0.3 미만 = 구내식당 권장. 응답 3명 미만은 「표본 적음」으로 함께 표시됩니다.

거리 표기 — 도로명주소 기준 직선 추정치이며, 도보 시간은 시속 약 4.6km로 환산한 값입니다. 실제 이동 시간은 [길찾기]로 확인하세요. 신호·경사·골목길 때문에 실제로는 더 걸릴 수 있습니다. 점심시간 내 왕복 가능성은 거리 기준 참고값입니다.

영업 상태 최신화

행정안전부 지방행정 인허가 데이터(일반음식점)와 현재 목록을 대조해, 폐업·말소로 확인된 곳은 삭제하고 영업 중으로 확인된 곳은 그대로 둡니다.

영업상태(영업/폐업)가 담긴 공식 파일은 LOCALDATA에서만 받을 수 있습니다. 접속이 느리면 시간대를 바꿔 재시도하거나 www.localdata.kr 주소로 시도해 보세요. 급하지 않다면 ①번 방법으로 충분합니다.
  1. LOCALDATA → 데이터받기 → 데이터다운로드를 엽니다. (로그인 불필요)
  2. 지역별 데이터에서 울산광역시 → 중구, 업종 일반음식점을 선택해 CSV를 내려받습니다. 카페·베이커리까지 점검하려면 휴게음식점 파일도 받아 한 번 더 올리면 됩니다.
  3. 내려받은 파일을 아래에 올립니다. 사업장명 · 영업상태 · 주소 열을 자동으로 찾아냅니다.
📂 CSV / JSON 파일을 여기에 끌어놓거나 클릭해서 선택
CP949(EUC-KR) 인코딩 CSV도 자동 처리 · 여러 파일을 차례로 올려도 안전
파일·인증키 없이 브라우저에서 바로 합니다. [검색]을 눌러 영업 여부를 확인한 뒤 ✓(운영) / ✕(폐업)를 표시하고 [적용]을 누르세요. ✕ 표시한 곳은 삭제되어 모든 사용자에게 반영됩니다.

설정

이 기기에서의 사용 방식입니다. 평가는 Firebase에 실시간으로 공유·누적됩니다.

모바일에서는 선택한 지도 앱으로 도보 경로를 바로 엽니다. 데스크톱에서는 웹 지도를 열고 출발지 주소를 클립보드에 복사합니다.
한줄평 옆에 표시됩니다. 비워두면 '익명'으로 등록됩니다.
경험 여부에 따라 설문 문항이 바뀝니다. 언제든 다시 바꿀 수 있습니다.
