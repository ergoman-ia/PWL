교육원 주변 식당 찾기

교육생용 · 구내식당 대비 평가 · 🚶 도보 기준
📍 기준점 교육원 정문

판단 배지 읽는 법 — 교육원 구내식당을 기준(0점)으로 두고, 구내식당을 먹어본 교육생의 비교 응답(−2 ~ +2)과 먹어보지 않은 교육생의 추천 응답을 함께 환산한 값입니다. ＋1.0 이상 = 나갈 만함, ＋0.3 ~ ＋1.0 = 가볼 만함, ±0.3 = 구내식당과 비슷, −0.3 미만 = 구내식당 권장. 응답 3명 미만은 「표본 적음」으로 함께 표시됩니다.

거리 표기 — 도로명주소 기준 직선 추정치입니다. 실제 이동 시간은 [길찾기]로 확인하세요. 점심시간 내 왕복 가능성은 거리 기준 참고값입니다.

목록 출처 — 공개 맛집 데이터베이스 기준 초기 목록입니다. 영업 여부는 [업데이트]로 행정안전부 인허가 데이터와 대조해 최신화하세요.

저장 — 브라우저에 저장하지 않습니다. 구글시트를 연결하면 평가가 공유·누적되고, 연결 전에는 [내보내기]로 JSON을 보관했다가 [불러오기]로 복원합니다.

영업 상태 최신화

행정안전부 지방행정 인허가 데이터(일반음식점)와 현재 목록을 대조해, 폐업·말소로 확인된 곳은 삭제하고 영업 중으로 확인된 곳은 그대로 둡니다.

인증키·서버 없이 가장 확실하게 동작하는 방법입니다. 브라우저 보안(CORS·혼합콘텐츠) 제약을 받지 않습니다.
  1. 공공데이터포털에서 「지방행정 인허가 – 일반음식점」 또는 LOCALDATA에서 울산광역시 중구 데이터를 내려받습니다. (CSV 또는 JSON)
  2. 내려받은 파일을 아래에 올립니다. 사업장명 · 영업상태 · 주소 열을 자동으로 찾아냅니다.
📂 CSV / JSON 파일을 여기에 끌어놓거나 클릭해서 선택
CP949(EUC-KR) 인코딩 CSV도 자동 처리
공공 API 서버는 브라우저 직접 호출(CORS)을 막아두는 경우가 많습니다. 실패하면 ①번 파일 방식을 쓰시거나 프록시 주소를 넣어 주세요.
키는 창을 닫으면 사라지며 조회 요청 외에는 전송·저장되지 않습니다.
[검색]으로 영업 여부를 확인한 뒤 ✓ / ✕ 를 눌러주세요. ✕ 표시한 곳은 [적용] 시 삭제됩니다.

설정 · 평가 공유

구글시트를 연결하면 교육생들이 남긴 평가가 한곳에 쌓이고, 모두가 같은 평균을 보게 됩니다.

길찾기 버튼은 선택한 지도에서 음식점 주소를 열고, 동시에 출발지 주소를 클립보드에 복사합니다. 출발지 칸에 붙여넣으면 됩니다.
배포 시 실행 계정: 나, 액세스 권한: 모든 사용자로 설정해야 교육생이 로그인 없이 쓸 수 있습니다.
한줄평 옆에 표시됩니다. 비워두면 '익명'으로 등록됩니다.
경험 여부에 따라 설문 문항이 바뀝니다. 언제든 다시 바꿀 수 있습니다.

  2. 메뉴 확장 프로그램 → Apps Script를 엽니다.
